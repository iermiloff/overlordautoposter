# 🤖 Overlord Autoposter Bot

Универсальный Telegram-бот для автоматического и ручного постинга контента в неограниченное количество каналов. Разработан на фреймворке **Aiogram 3** и оптимизирован для работы менеджеров через единый, не забивающий историю чата интерфейс.

---

## 🌟 Основные возможности

* 📦 **Полноценная админка**: Просмотр, активация/деактивация, удаление и ручной запуск постов из меню бота.
* 📂 **Поддержка медиа**: Постинг чистого текста, картинок, видеороликов и GIF-анимаций (как напрямую, так и по `file_id`).
* 🔗 **Конструктор инлайн-кнопок**: Пошаговый ввод названий и URL-ссылок для создания интерактивных кнопок под постами.
* ⏳ **Гибкие интервалы**: Настройка таймера для автоматического цикличного постинга (в минутах) индивидуально для каждого поста.
* 📢 **Динамический таргетинг**: Бот автоматически сканирует каналы, где он является администратором. Менеджер может «галочками» выбирать целевые каналы при создании или редактировании поста.
* ⚡ **Zero-Spam UI**: Весь интерфейс работает на динамическом редактировании сообщений и зачистке временных шагов ввода, минимизируя нагрузку на Telegram API.

---

## 🏗 Технологический стек

* **Язык**: Python 3.11
* **Фреймворк**: Aiogram 3 (Long Polling + FSM)
* **База данных**: SQLite (хранится в изолированном Docker-volume)
* **Контейнеризация**: Docker & Docker Compose

## 🚀 Быстрый запуск на собственном сервере

### 1. Клонирование репозитория
```bash
git clone https://github.com/iermiloff/overlordautoposter
cd overlordautoposter
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта:
```bash
nano .env
```
Заполните его вашими конфигурационными данными:
```env
BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
ADMIN_IDS_RAW=123456789,987654321
```
> *Где `ADMIN_IDS_RAW` — это Telegram ID менеджеров (через запятую без пробелов), которые получат доступ к админ-панели.*

### 3. Развертывание через Docker
Запустите сборку и старт контейнера в фоновом режиме:
```bash
docker compose up -d --build
```

## 📖 Инструкция для менеджеров

1. **Инициализация**: Откройте чат с ботом и введите команду `/start`.
2. **Подключение каналов**: 
   * Добавьте бота в ваш Telegram-канал.
   * Назначьте его **администратором** с правом публикации сообщений.
   * Перейдите в боте в пункт `🔍 Просканировать каналы` — канал автоматически привяжется к системе.
3. **Создание публикации**: 
   * Нажмите `➕ Добавить пост`.
   * Пошагово отправьте: Текст ➡️ Медиафайл (или `-`) ➡️ Отметьте целевые каналы галочками ➡️ Сформируйте инлайн-кнопки ➡️ Укажите интервал.
4. **Управление ротацией**: В разделе `📋 Список постов` вы можете в любой момент выключить автопостинг конкретного сообщения, изменить его содержимое или нажать `🚀 Опубликовать сейчас` для мгновенной отправки вне очереди.
